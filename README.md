# IT-Troubleshooting-Guide

A beginner-friendly guide to troubleshooting common computer problems.
This project documents basic IT troubleshooting steps and solutions for common computer issues.

## 1. Computer Won't Turn On

### Possible Causes

- Power Cable is disconnected
- Battery is dead
- Charger is faulty
- Power button or hardware problem

  ### Troubleshooting Steps

  1. Check that the power cable is connected.
  2. If it's a laptop, connect the charger.
  3. Try a different power outlet.
  4. Hold the power button for about 10 seconds, then try turning it on again
